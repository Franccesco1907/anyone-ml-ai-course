# Work with each resource format

The course player combines lesson pages with embedded viewers and links to external resources. A page labeled as text may contain several notebooks, recordings, or downloads. The syllabus records platform content kinds separately from observed resource formats.

| Observed resource | Private study workflow | Public learning evidence |
|-------------------|------------------------|--------------------------|
| PDF presentation or document viewer | Read the source and record slide/page references. Retain an original copy only when permitted. | An explanation, your own diagram, and a worked example. |
| Embedded video or recording | Record the lesson ID and useful timestamps. Use an available authorized transcript or your own notes. | A short explanation of a concept and a practice result. |
| Colab, Drive, or notebook link | Open the linked notebook when studying, keep the supplied version private, and make a working copy as permitted. Record dependencies before running it. | Your own experiment with safe outputs and enough instructions to reproduce it. |
| Download or project link | Check the actual file type after an authorized download. A Drive link alone does not establish the file format. | Original project documentation and code you may publish. |
| DOCX resume template | Maintain your personal version privately. Review contact details before sharing any resume. | A portfolio description of your projects, with personal data shared deliberately. |
| Quiz, survey, or assignment | Complete it yourself in the academy and follow its submission instructions. | A separate explanation or analogous exercise, keeping assessment answers private. |

The inventory covers lesson structure and resource references. It does not establish that every linked file is accessible, licensed for redistribution, or executable. Original assets were not bulk-downloaded, videos were not watched, and notebooks were not run during inventory work.

## Prepare a focused NotebookLM workspace

Start with the current Data Science module rather than importing every course at once. Select permitted sources that answer the question you are studying. Keep the original sources backed up separately and bring verified conclusions back into your own notes.

NotebookLM accepts formats including PDF, PPTX, Markdown, text, and DOCX. A web-page import does not automatically import its embedded videos or nested pages. Jupyter `.ipynb` is not listed as a supported source format; prepare a Markdown explanation with relevant code and outputs when needed. Public YouTube imports require captions and use their transcript. See the [official source documentation](https://support.google.com/notebooklm/answer/16215270?hl=en).

Use the [question template](../templates/question.md) to record your attempt before asking the tutor for help. Check citations and reproduce the idea in a new example before recording it as understood.
