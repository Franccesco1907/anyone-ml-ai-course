# AnyoneAI Learning Journal

My personal workspace for studying machine learning and AI with AnyoneAI. It holds my own English notes, questions, practice, project work, and evidence of progress. This is an unofficial learning journal.

## Start a study session

1. Choose a course below and identify the next lesson in the platform.
2. Copy [the session template](templates/session.md) to `sessions/YYYY-MM-DD-topic.md`.
3. Create a lesson note or question inside the course folder using [the templates](templates/README.md).
4. End with a small exercise completed unaided and update [progress](progress/README.md) with the result.

For the first session, spend 10–15 minutes identifying one lesson, recording its source, and writing one question. Actual lesson order will come from the platform; it has not been inventoried yet.

## Publishing boundary

Publish your own explanations and code. Keep course slides, videos, downloaded notebooks, assessments, restricted datasets, answer keys, personal information, and credentials outside this repository. Record source references without reproducing the material. Review files and notebook outputs before every push; `.gitignore` is only a backup.
