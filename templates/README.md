# Reusable learning templates

Copy a template and replace its bracketed prompts with observations from your own work. Leave unknown information explicit; templates are not completed study records.

| Template | Destination |
|----------|-------------|
| [Lesson](lesson.md) | `courses/<course>/modules/<module>/notes/<lesson>.md` |
| [Question](question.md) | `courses/<course>/modules/<module>/questions/<question>.md` |
| [Session](session.md) | `sessions/YYYY-MM-DD-topic.md` |
| [Project](project.md) | `projects/<project>/README.md` |
| [Learning notebook](learning-notebook.ipynb) | A course exercise or project folder. |

For notebooks, retain concise, safe results and plots from your own work as visible evidence. Clear sensitive or large outputs, and inspect all cells for source content, secrets, and personal data. Record dependencies once you actually need them; the scaffold installs no environment.
